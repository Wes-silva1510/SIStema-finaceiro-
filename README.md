# Mini Sistema Financeiro (Django + React)

Projeto de estudo com contas, transferências e extrato, usando Django REST Framework no back-end e React no front-end.

Destaques: Decimal para dinheiro, transaction.atomic, select_for_update, chave de idempotência e testes automatizados.

O código e as instruções para rodar estão na pasta [financeiro-simples](./financeiro-simples).
